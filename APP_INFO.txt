3. CORE FEATURES & MECHANICS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3.1 PROFILE — THE "FOLIO"
  Each user has a Folio (profile) containing:
    • CV Upload (PDF/image) → parsed into beautiful cards
    • 3 "Chapter" Prompts (like Hinge prompts but CV-inspired):
        e.g. "My proudest side project was..."
             "The skill I'm still unlearning is..."
             "If my CV could lie, it would say..."
    • 1 Voice Note (30 sec) — humanises the profile
    • Ambition Tags: 5 max (e.g. #StartupLife #PhDLife #FitnessCulture)
    • Intent Badge: 🔴 Dating  🔵 Friends  🟡 Collab  🟢 Mentorship (pick 1-2)
    • Anonymous Name: System-generated codename (e.g. "Arctic_Volta_88")
    • Avatar: Silhouette/abstract shape (reveals in stages)

3.2 THE DAILY DROP (Core Loop — ADDICTIVE MECHANIC)
  Every day at 9:00 AM local time:
    • 4 new curated Folio matches arrive ("Your 4 Today")
    • User reviews each one (CV cards, prompts, voice note, tags)
    • For each: "Continue" or "Pass" (swipe-free — intentional tapping)
    • Timer: 24 hours to decide, or the match expires → FOMO trigger
    • Notification: "⏰ Your folios expire in 2 hours" — urgency loop

  Psychology: Scarcity (only 4) + Time pressure (24hr) + Variable reward
  (who are they?) + Anticipation (9AM ritual) = Habit formation.

3.3 THE PROGRESSIVE CONNECTION LADDER
  Stage 1 — SPARK (Day 0-1):
    Both tap "Continue" → Mutual match confirmed
    → Unlock: First names revealed, 5 chat messages/day limit
    → Goal: Keep friction high, make each message feel precious

  Stage 2 — THREAD (Day 1-30):
    Daily check-in prompt: "Still feeling it? Yes / Not anymore"
    → Both must confirm "Yes" each day to maintain connection
    → Gradual reveal: Day 7 → first photo reveal, Day 14 → full name,
      Day 21 → LinkedIn optional share, Day 30 → full unlock
    → If either says "Not anymore" → graceful exit, no ghost
    → Chat: unlimited after Day 7

  Stage 3 — FOLIO (Permanent — Day 30+):
    If both complete 30 days → "Permanent Connection"
    → User chooses next step: Date / Friend / Collaborate / Mentor
    → Added to "My People" section permanently
    → Special "1 Year" and anniversary notifications

  Psychology: Commitment escalation + Sunk cost (invested 30 days) +
  Reciprocity (daily check-ins) + Anticipation (what do they look like?)

3.4 ANONYMOUS PROFILE SYSTEM
  Phase 1 (Pre-match): Full anonymity
    - Codename only ("Arctic_Volta_88")
    - Abstract geometric avatar (algorithmically generated per user, consistent)
    - CV parsed into skill tags (no employer names shown until Day 14)
    - Location: City level only ("London, UK")

  Phase 2 (Spark): Partial reveal
    - First name only
    - Abstract avatar + hair color silhouette

  Phase 3 (Thread Day 7+): Gradual reveal
    - Profile photo (single, chosen by user)
    - Full CV becomes visible

  Phase 4 (Permanent): Full identity
    - All details unlocked
    - Option to exchange social handles

  Anti-harassment: Block/Report at any stage. No screenshots (blurred in-app).

3.5 NOTIFICATIONS (Engineered Triggers)
  External Triggers (Pull):
    • 9:00 AM: "Your 4 Folios have arrived ✨" (Daily Drop)
    • 2 hrs before expiry: "⏰ [Name] expires in 2 hours"

4. MATCHING ALGORITHM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Signals used for matching (non-AI):
  1. Intent alignment (Dating↔Dating, Friends↔Friends, etc.)
  2. Industry/field similarity (extracted from CV)
  3. Education level & institution type (optional)
  4. Ambition Tag overlap (Jaccard similarity ≥ 2 shared tags)
  5. Geographic proximity (city-level, configurable radius)
  6. Activity level (last active, response rate — fresh users first)
  7. "Folio completeness" score (rewards full profiles)
  8. Mutual avoidance: users who passed on each other recently not re-matched for 30 days

No AI black-box — algorithm is explainable and user can see match reasons:
  "Matched because: same industry, 3 shared tags, both in London"

7. PSYCHOLOGY & ADDICTIVE DESIGN (Ethical Engagement)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

7.1 Nir Eyal's Hook Model applied:
  TRIGGER  → 9AM push "Your Folios are here" (external) → ritual habit (internal)
  ACTION   → Open app, review 4 Folios (simple, effortful enough to feel intentional)
  REWARD   → Variable: will they like me back? Who are these people? (dopamine)
  INVEST   → User writes thoughtful messages, maintains streak (sunk cost + ownership)

7.2 Psychological Principles Used:
  ► Scarcity Principle: Only 4 matches/day — each feels rare and special
  ► Loss Aversion: 24hr timer — "miss them forever if you don't decide"
  ► Reciprocity: Mutual opt-in required — both must say YES → feels earned
  ► Social Proof: "3 people found your Folio interesting today" → validation
  ► Zeigarnik Effect: Open loops (who matched me? who passed?) keep users thinking
  ► Progressive Disclosure: Gradual identity reveal creates "parasocial build-up"
  ► Endowment Effect: Users who invest in a 15-day Thread feel it has high value
  ► Anticipation > Reward: "Your 4 Folios drop in 6 hours" notification builds excitement
  ► FOMO: "Match expires in 2 hours" creates urgency without being manipulative
  ► Identity investment: "My Folio" framing = the app is about YOU, not swiping others
  ► Completion bias: Folio Score % drives profile completion (97% = "almost there!")

7.3 Ethical guardrails (trust builders):
  ► "Take a break" mode — pause all threads for up to 2 weeks guilt-free
  ► Weekly digest instead of daily if requested
  ► "Mindful matching" toggle — only 1 match/day option
  ► Transparent algorithm — always show WHY you matched
  ► Graceful exit — always easy to end a Thread with dignity
